## 题目结构

每道题通常包含以下三个部分：

1. **题目要求**：需要完成的功能或脚本目标
2. **考察点**：题目对应的知识点
3. **操作提示**：实现思路或可参考的代码片段

示例：

> **题目要求**：编写一个方法 `CalculateDamage(int baseDamage, int defense)`，计算实际伤害并返回结果。
>
> **考察点**：方法定义、参数传递、返回值、基础数学运算。
>
> **操作提示**：实际伤害 = 基础伤害 - 防御力，最小为 1，可使用 `Mathf.Max` 处理边界值。

## 使用方法

### 1. 克隆仓库

```bash
git clone git@github.com:endless-summer222/unity-quiz-bank-Chinese-only-.git
```

也可以使用 HTTPS：

```bash
git clone https://github.com/endless-summer222/unity-quiz-bank-Chinese-only-.git
```

### 2. 查看规划

先打开 `Unity操作题库规划.docx`，了解整体模块划分和学习路线。

### 3. 开始练习

在 `题目/` 目录中打开对应模块的 Word 文档，按顺序完成题目。建议每道题都在 Unity 中新建场景或脚本实际操作，不要只看不练。

## 常见问题

### 推送时出现 `ssh.exe ... CreateFileMapping ... Win32 error 5`

这是 Git 自带的 SSH 程序在部分受限 Windows 环境下无法正常运行导致的，可以切换为 Windows 自带的 OpenSSH：

```bash
git config core.sshCommand "C:/Windows/System32/OpenSSH/ssh.exe"
git push -u origin master
```

> 在正常的个人电脑上通常不会遇到此问题，该配置仅在受限环境中需要。
